# 図表で用いている指標

`script/figures.py` が出力する表・図の各量について、定義・グラフ理論上の意味・
本研究での解釈・注意点をまとめる。

## グラフの構成（前提）

- **頂点** = AL-CPL の概念のうち、教科書コーパスの本文に出現したもの
- **辺** = 有向。`A → B` は「A を B より先に導入した教科書が存在する」
- **重み** = その順序で並べた教科書の冊数（1 冊 1 票、上限は分野の冊数）
- 著者間で順序が割れたペアには **両向きの辺が立つ**
  （10 冊中 7 冊が A 先なら `w(A→B)=7`, `w(B→A)=3`)

辺を張るかどうかは「同じ節に共起したか」で決め、向きの投票は
「両方の概念を扱う教科書すべて」から取る。両者を分けているのは、
共起した本だけに投票を限ると使える証拠が減り推定が不安定になるため。

|---|---|---|
| Books | その分野の教科書数 | **AL-CPL の概念を 1 つ以上含む本**のみ数える。precalculus は 13 冊取得したが 1 冊は概念を含まず 12 |

| Pairs | AL-CPL のラベル付き概念ペア数 | データセット側の値 |
| Positive | うち先修関係が成立するペア数 | `(a, b)` が正例 = 「a を学ぶには先に b が必要」 |
| Evaluated | スコアを計算できたペア数 | 両概念が本文に出現し、かつ同じ節に共起した場合のみ |

**Evaluated が Pairs より小さい理由は 2 つ**:
概念が本文に出現しない（被覆の問題）か、2 概念が一度も共起しない（辺が張られない）。

## fig_coverage.pdf

AL-CPL の概念のうち、何個が本文に出現したか。

照合は完全一致ではなく、以下の変換を経る。

1. 下線を空白に (`Magnetic_field` → `Magnetic field`)
2. Wikipedia の曖昧性解消の括弧を除去 (`Position_(vector)` → `Position`)
3. 小文字化
4. 語尾の複数形を許容 (`\bwave(?:e?s)?\b`)

**2 は意味を広げる**。`Work_(physics)` が動詞の work に一致しうるため、
被覆率は上限であって適合率ではない。

## tab_graph.tex

| 列 | 定義 | グラフ理論での意味 | 本研究での意味 |
|---|---|---|---|
| **Nodes** | \|V\| | 頂点数 | 本文に出現した概念数 |
| **Edges** | \|E\| | 有向辺数 | 観測された順序関係の数 |
| **Mean degree** | \|E\| / \|V\| | 平均次数 | 1 概念が平均していくつの概念と順序関係を持つか |
| **Density** | \|E\| / (\|V\|(\|V\|−1)) | 可能な有向辺に対する実在率、0–1 | 概念ペアのうち順序が観測された割合 |
| **Recipr.** | 逆向きの辺も存在する辺の割合 | 相互性 (reciprocity) | **著者間で順序が割れた度合い** |
| **Median / Max weight** | 重みの中央値・最大値 | 辺の多重度 | その順序を支持した教科書数 |
| **Largest SCC (both)** | 最大強連結成分のサイズ | — | 両向きを含めたときの循環の規模 |
| **Largest SCC (major.)** | 多数派の向きだけを残した場合の最大強連結成分 | — | **多数決後も残る矛盾の規模** |

### 平均次数について

有向グラフでは `Σ出次数 = Σ入次数 = |E|` なので、`|E|/|V|` は
**出次数の平均であると同時に入次数の平均**。「出」に固有の情報ではない。

### 密度について

現実のネットワークは通常 0.01 未満。本研究の 0.43–0.49 は極めて高く、
**可能なペアの約半分に辺がある**。原因は共起ウィンドウが節全体
（中央値 26 段落）と広いこと。密度が高いと SBM はブロック構造を
検出しにくくなるため、結果の解釈時に踏まえる必要がある。

### 相互性について

**「両向きの辺を張る」表現を取る場合にのみ意味を持つ。**
多数派の向きだけを残したグラフでは定義上 0 になる。

冊数とともに上がる（2 冊 0.139 → 5 冊 0.608 → 10 冊 0.745）。
これは「冊数が増えるほど著者の不一致が観測される」ことを示し、
手法が前提とする現象そのものの可視化になっている。

### 強連結成分 / 弱連結成分

- **弱連結**: 辺の向きを**無視**して繋がっているか
- **強連結**: 辺の向きに**従って**互いに行き来できるか

```
A ──→ B ──→ C        A ──→ B ←── C
↑           │
└───────────┘        A から B へは行けるが B から A へは行けない
強連結                 弱連結ではあるが強連結ではない
```

**すべての強連結成分がサイズ 1 ⟺ そのグラフは閉路を持たない (DAG)**。
先修関係は本来 DAG であるべきなので、最大 SCC のサイズは
**「先修関係として循環している概念の塊の大きさ」**を表す。

本研究では多数決後も物理で 136 概念中 115 個が 1 つの塊になる。

```
A→B (7 冊), B→C (6 冊), C→A (6 冊)
各ペアの多数決は成立するが、3 つ合わせると矛盾する
```

**各ペアの多数決からは一貫した順序が得られない**という限界を示す。
一貫した順序を得るには最小フィードバック弧集合の除去などが要る。

なお data_mining のみ DAG になるのは、2 冊しかなく順序が割れようが
ないため。1 冊なら必ず DAG になるのと同じ理屈。

## fig_weights.pdf

- **上段: 辺の重みの分布** — 分野で上限が違う（物理 10、data_mining 2）ため
  y 軸は共有していない。分野間の直接比較はできない
- **下段: 順序一致度の分布** — `max(w) / (w_fwd + w_rev)`。0.5–1.0 に
  正規化されるので**分野を跨いで比較できる**。投票が 3 冊未満のペアは除外

0.5 は著者が真っ二つに割れた状態、1.0 は全著者が同じ順序で導入した状態。

**分布の形は冊数に制約される。** 5 冊なら取りうる割合は 0.6 / 0.8 / 1.0 に
限られ、geometry で 0.9 が空なのはこのため。形の直接比較はできない。
